# Protected Code

The tokenizer should prevent plugin expansion inside fenced code blocks.

```
:emoji-fire:
:emoji-smile:
:icon-github:
:icon-terminal:
H~2~O
x^2^
```

Inline code should also remain untouched: `:emoji-fire:` `:icon-github:` `x^2^`
